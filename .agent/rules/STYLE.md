# Visual & Copy Style Guidelines

## Core Directives

### 1. Mandatory Copy Approval Rule
> **MANDATE**: ALWAYS ask for user confirmation before writing or updating any user-facing copy.
- Never invent dramatic, pseudo-cosmic, corporate, or hyperbolic filler ("Unleash your strategic mastery", "Welcome to the cosmic arena", "Synergy", etc.).
- Keep all UI text restrained, functional, authentic, and concise (resembling high-craft tools like Linear, Raycast, or minimal tactical games).
- Before placing copy into mockups, templates, or components, explicitly present the candidate text strings to the user and obtain their confirmation.

### 2. Anti-AI-Slop Visual Principles
- **No Default Palettes**: Reject generic white cards on dark grey, default Tailwind indigo buttons, or unstyled tables.
- **Layered Neutrals**: Use subtle, layered dark neutrals (`#090a0f`, `#0e111a`, `#141824`, `#1b2132`) with 1px border stroke tokens (`rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.12)`).
- **Intentional Typography**: Clean, high-readability sans pairings with monospace tabular data figures for metrics, timers, and ratings.
- **Balanced Proportions**: 
  - Restrain vertical height so screens fit standard viewports without needless scrolling.
  - Fix board-to-panel ratios on game screens (Deck Builder board must anchor the view; tactical hand and combat log must frame the board harmoniously without oversized cards).
  - Use consistent corner radii (e.g., 6px–8px for technical tactical feel) and compact, deliberate padding.
