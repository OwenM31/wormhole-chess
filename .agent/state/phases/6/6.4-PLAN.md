  <name>Create Multi-Worker Monte Carlo Simulation Script (`scripts/simulate-deck-balance.mjs`)</name>
  <files>scripts/simulate-deck-balance.mjs</files>
  <action>
    Create `scripts/simulate-deck-balance.mjs` (or `.ts` invoked with `tsx` / Node worker threads):
    1. Implement **Stratified Balanced Block Deck Sampling**:
       - Each block of 9 matches (`18` 8-card hands = `144` card slots) shuffles the 36-card pool 4 times so every single card $c \in \{1..36\}$ appears **4 times per block** (twice for White, twice for Black), guaranteeing zero sampling bias across the 36 cards.
       - Default tournament size: configurable via `--games=N` CLI flag (default `360` games = `720` deck appearances = `160` appearances per card across all 36 cards), distributed across `os.cpus().length` parallel worker threads/processes.
    2. Per-Match Execution Loop:
       - Initialize `new DeckChessEngine(undefined, whiteDeck, blackDeck)`.
       - On each ply (up to `MAX_PLIES = 64`):
         - Record `turnsHeld` for each unique unspent card in the active player's hand.
         - Check `engine.getEmpoweredMoves(undefined, true)` and record `turnsConditionMet` for each unique card ID that has $\ge 1$ legal empowered move on this turn.
         - Compute AI move via `computeBestTurn(engine, activeColor, 'medium')` with slight random tie-breaking (`±8cp` jitter on equal-scoring opening moves so every game follows a distinct trajectory).
         - If `decision.type === 'empowered'`, record `timesPlayed` and `evalSwingCp` (`evaluateBoard(after) - evaluateBoard(before)`).
       - If game reaches `MAX_PLIES` without checkmate/draw, adjudicate by material + positional evaluation (`> +250cp` = White win, `< -250cp` = Black win, else Draw).
    3. Aggregation & Report Generation:
       - Compute per-card `triggerRate` (`turnsConditionMet / turnsHeld`), `playRate` (`timesPlayed / appearances`), `avgSwingCp`, `winRate` (`(wins + 0.5 * draws) / appearances`), and `winRateDelta` (`winRate - 0.50`).
       - Write `.agent/state/phases/6/balance-metrics.json` and `.agent/state/phases/6/BALANCE_REPORT.md` including:
         - Executive Summary (Total games, total plies, White/Black/Draw split, average cards played per match).
         - Full 36-Card Telemetry Table sorted by Composite Power / Win-Rate Delta.
         - Outlier Analysis flagging:
           - **Under-Triggered / Dormant Cards** (`Trigger Rate < 3%` or `Play Rate < 8%`).
           - **Over-Dominant Cards** (`Win Rate > 58%` or `Play Rate > 75%`).
  </action>
  <verify>node scripts/simulate-deck-balance.mjs --games=36</verify>
