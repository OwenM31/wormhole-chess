    Create `src/components/EvalBar.tsx`:
    1. Define props:
       ```ts
       export interface EvalBarProps {
         whiteCp: number;
         whiteWinPct: number; // 0 to 100
         displayLabel: string; // e.g. "+1.4", "0.0", "-0.8", "M2"
         orientation?: 'w' | 'b';
         className?: string;
       }
       ```
    2. Render a vertical container (`w-full h-full rounded-sm overflow-hidden border border-[rgba(139,126,116,0.45)] bg-[#1E2022] relative select-none shadow-md`) with `data-testid="eval-bar"`.
    3. Orientation handling:
       - When `orientation === 'w'`, White (`#FAF9F6`) fills from the **bottom** upward (`height: ${whiteWinPct}%` anchored at `bottom: 0`), while Black (`#1E2022`) occupies the top.
       - When `orientation === 'b'`, White (`#FAF9F6`) fills from the **top** downward (`height: ${whiteWinPct}%` anchored at `top: 0`), so the player's own color always grows upward from the bottom edge of the bar.
       - Apply `transition-all duration-300 ease-out` on the fill height so the bar glides smoothly after each move or card play.
    4. Numeric readout (`data-testid="eval-bar-score"`):
       - Position the `displayLabel` (`text-[9px] sm:text-[10px] font-mono font-extrabold tracking-tighter leading-none`) inside the bottom edge (if the bottom player is winning/even) or top edge (if the top player is winning) with contrasting text color (`#191B1D` on White fill, `#FAF9F6` on Black fill).
       - Add a `title` tooltip showing `"Position Evaluation: ${displayLabel} (${whiteCp >= 0 ? 'White' : 'Black'} advantage)"`.
  </action>
