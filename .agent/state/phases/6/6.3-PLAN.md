<task type="auto">
  <name>Wire Unified AI Turn, Live Evaluation & Hint Actions in `useDeckChessGame.ts`</name>
  <files>src/hooks/useDeckChessGame.ts</files>
  <action>
    Update `src/hooks/useDeckChessGame.ts`:
    1. Update `aiDifficulty` option type to `AiDifficulty` (`'easy' | 'medium' | 'tactical' | 'grandmaster'`).
    2. In `triggerAiTurn`:
       - Remove the legacy 0-ply greedy `empoweredMoves` loop (`bestEmpoweredGain >= 30`).
       - Call `const decision = computeBestTurn(engine, aiColor, aiDifficulty);`.
       - If `decision.type === 'empowered' && decision.empoweredMove`:
         - Execute `engine.makeEmpoweredMove(decision.empoweredMove)`, play card/capture/check/game-over sounds, append combat log & `RecordedTurn`, and `syncState()`.
       - Else (`decision.type === 'standard'`):
         - Execute `engine.makeMove(decision.move)`, play sounds, append combat log & `RecordedTurn`, and `syncState()`.
    3. Compute live `evaluation: PositionEvaluation` using `useMemo(() => evaluatePosition(engineRef.current), [gameState.fen, gameState.whiteHand.length, gameState.blackHand.length, gameState.isGameOver])`.
    4. Add Engine Hint state and actions:
       - `const [hintMove, setHintMove] = useState<BestTurnResult | null>(null);`
       - Clear `hintMove` automatically inside `cancelPendingCardMove()`, `makeMove()`, `confirmPendingCardMove()`, `applyRemoteTurn()`, and `resetGame()`.
       - `requestHint`: If `hintMove` is already set, toggle it off (`setHintMove(null)`). Otherwise compute `const best = computeBestTurn(engineRef.current, engineRef.current.getTurn(), 'tactical')` and `setHintMove(best)`.
       - `clearHint`: `setHintMove(null)`.
       - `applyHintMove`: If `!hintMove`, return. If `hintMove.type === 'empowered' && hintMove.empoweredMove`, populate `previewFen` (if not already populated via `engineRef.current.getEmpoweredMoves()`) and stage it into `setPendingCardMove(...)` so the player sees the board preview and can click `✓ Confirm` (or if in AI mode on player's turn, stage `pendingCardMove` and clear `hintMove`). If `hintMove.type === 'standard'`, call `makeMove(hintMove.move.from, hintMove.move.to, hintMove.move.promotion)` and clear `hintMove`.
    5. Return `evaluation`, `hintMove`, `requestHint`, `clearHint`, and `applyHintMove` from `useDeckChessGame`.
  </action>
  <verify>npx tsc --noEmit</verify>
  <done>`useDeckChessGame.ts` delegates AI turns to `computeBestTurn`, computes live `evaluation`, and provides `hintMove`, `requestHint`, `clearHint`, and `applyHintMove`.</done>
</task>
