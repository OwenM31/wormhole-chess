# Plan 8.2: Atomic Resumable Single-Match Harness, Color-Swapped Schedule & De-Confounded Ridge Aggregator

<objective>
Create an atomic single-game simulation module and CLI (`scripts/sim-single-match.ts`), upgrade the multi-worker tournament runner (`scripts/simulate-deck-balance.mjs` and `scripts/deck-balance-worker.ts`) to use color-swapped stratified blocks and incremental per-worker JSONL persistence (stoppable and resumable at any moment), and build the standalone statistical aggregator (`scripts/aggregate-deck-balance.ts`) computing Search-Backed Card Lift, Color-Cancelled Win Delta, and Ridge-Regularized Marginal Card Credit.

Purpose: Eliminates the 42-ply premature cutoff, White/Black color bias, and 8-card teammate confounding, while allowing simulations of any size to be paused, inspected, or resumed at any instant.
Output: `scripts/sim-single-match.ts`, `scripts/aggregate-deck-balance.ts`, updated `scripts/deck-balance-worker.ts`, `scripts/simulate-deck-balance.mjs`, and harness tests in `scripts/verify-phase8-engine-and-harness.ts`.

  <name>Task 1: Create Atomic Single-Match Runner (scripts/sim-single-match.ts)</name>
  <files>scripts/sim-single-match.ts</files>
  <action>
    Create `scripts/sim-single-match.ts` exporting `MatchSpec`, `MatchCardTelemetry`, `MatchRecord`, and `playSingleMatch(spec: MatchSpec): MatchRecord`:
    1. **Inputs (`MatchSpec`)**:
       - `matchId: string` (e.g., `"b00_p0_w"` and its color-swapped twin `"b00_p0_b"`)
       - `blockId: number`
       - `pairId: string`
       - `seed: number`
       - `whiteDeck: string[]` (8 card IDs)
       - `blackDeck: string[]` (8 card IDs)
       - `maxPlies?: number` (default `100`)
       - `difficulty?: AiDifficulty` (default `'medium'`)
    2. **Match Execution Loop**:
       - Initialize `new DeckChessEngine(undefined, spec.whiteDeck, spec.blackDeck)`.
       - Derive a per-ply deterministic seed `plySeed = (spec.seed * 1664525 + plies * 1013904223) >>> 0` and call `computeBestTurn(engine, turn, difficulty, DEFAULT_EVAL_PARAMS, { seed: plySeed })`.
       - Record the first 6 plies in `openingMoves6: string[]` (e.g. `["c2-c4", "g8-f6", ...]`).
       - When an empowered move is chosen (`decision.type === 'empowered'`), record:
         - `timesPlayed += 1`
         - `swingSum += evalAfter - evalBefore` (legacy naive swing for comparison)
         - `liftSum += decision.cardLiftCp ?? 0` (**Search-Backed Card Lift**: exact root search advantage of playing the card over the best standard chess move on that turn).
       - **Quiescence-Backed Mercy & Terminal Adjudication**:
         - Pure board evaluation helper `evaluateBoardPure(engine)`: evaluates material + PST + bishop pair + active shields **without** unspent hand retention so end-of-game adjudication never rewards hoarding unplayed cards.
         - If `plies >= 30` and `|pureEvalCp| >= 650` (and not in the middle of a hanging capture) for `4` consecutive plies, adjudicate early with `finishReason: 'mercy_adjudication'`.
         - If `plies === maxPlies` (`100`) without natural checkmate/draw, adjudicate via `pureEvalCp` (`>= 140` White win, `<= -140` Black win, else draw) with `finishReason: 'max_plies_adjudication'`.
    3. **Standalone CLI**:
       - Support running `npx tsx scripts/sim-single-match.ts --seed=42 --white=p1_sidestep,... --black=...` (or default starter decks if omitted) and printing the JSON `MatchRecord` to stdout.
    AVOID: Adjudicating `max_plies_adjudication` using `evaluateBoard` with unspent hand retention included—that biases adjudication toward whichever side hoarded more cards.
  </action>

  <done>scripts/sim-single-match.ts runs standalone and outputs a complete MatchRecord with winner, finishReason, openingMoves6, and per-card liftSum/swingSum telemetry.</done>

<task type="auto">
  <name>Task 2: Build De-Confounded Ridge Aggregator & Resumable JSONL Multi-Worker Runner</name>
  <files>scripts/aggregate-deck-balance.ts, scripts/deck-balance-worker.ts, scripts/simulate-deck-balance.mjs</files>
  <action>
    1. Create `scripts/aggregate-deck-balance.ts`:
       - Reads all `MatchRecord` lines from `.agent/state/phases/{phase}/matches.jsonl` (or `.agent/state/phases/{phase}/workers/worker_*.jsonl` if a run is currently in progress / was interrupted!).
       - Deduplicates by `matchId` so partial/resumed runs never double-count a game.
       - Computes for each of the 36 cards:
         - `appearances`, `whiteAppearances`, `blackAppearances`
         - `triggerRate`, `playRate` (`timesPlayed / appearances`), `avgSwingCp`, and **`avgLiftCp`** (`liftSum / timesPlayed`)
         - `winRate`, `winRateDelta`, and **95% confidence interval half-width** (`ci95 = 1.96 * sqrt(p * (1 - p) / n)`)
         - **Color-Cancelled Pair Win Delta (`pairedWinDelta`)**: across completed color-swapped twin pairs `(match_w, match_b)`.
         - **Ridge-Regularized Marginal Win Credit (`marginalCreditDelta`)**: solves $(X^T X + \lambda I)\beta = X^T (y - \bar{y})$ with $\lambda = 8.0$, where $X_{m, i} = +1$ if card $i \in \text{WhiteDeck}_m$, $-1$ if $i \in \text{BlackDeck}_m$, $0$ otherwise, and $y_m \in \{1, 0.5, 0\}$ (adjusted for mean White win rate $\bar{y}$). This isolates each card's true win-rate contribution independent of the other 7 cards in the deck!
       - Computes tournament-wide metrics:
         - **Natural Termination Breakdown**: `% Checkmate`, `% Mercy Adjudication`, `% Draw/Stalemate/Repetition`, `% Max-Ply Adjudication`.
         - **Opening Diversity**: count of unique 2-ply and 6-ply opening sequences across all matches.
       - Writes `.agent/state/phases/{phase}/balance-metrics.json` and `.agent/state/phases/{phase}/BALANCE_REPORT.md` (including Top 10 Strongest & Top 10 Weakest tables ranked by **De-Confounded Marginal Credit** and **Raw Win Rate**).
    2. Update `scripts/deck-balance-worker.ts` and `scripts/simulate-deck-balance.mjs`:
       - Generate **Color-Swapped Stratified Blocks** of **18 matches** per block (9 random 8v8 partitions of the 144-card pool $\times$ 2 color orientations: `b{B}_p{P}_w` and `b{B}_p{P}_b`). Every card appears 8 times per block (4 White, 4 Black against the exact same opposing 8-card deck).
       - Persist `.agent/state/phases/{phase}/schedule.json` (if not already present or if `--reset` is passed).
       - Scan `.agent/state/phases/{phase}/workers/worker_*.jsonl` and `matches.jsonl` for already-completed `matchId`s and skip them automatically!
       - Each worker appends every completed `MatchRecord` immediately via `fs.appendFileSync(workerJsonlPath, JSON.stringify(record) + '\n')`.
       - When workers finish (or even if stopped early and `npx tsx scripts/aggregate-deck-balance.ts --phase={phase}` is run), consolidate `worker_*.jsonl` into `matches.jsonl` and generate `balance-metrics.json` + `BALANCE_REPORT.md`.
    AVOID: Overwriting existing `worker_*.jsonl` files on resume unless `--reset` is explicitly passed.
  </action>
