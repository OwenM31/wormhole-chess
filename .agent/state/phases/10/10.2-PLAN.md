# Plan 10.2: Card Tag Tooltips (Desktop) & Tap-Popovers (Mobile) in Move Log

## Objective
Implement interactive card tag previews across both desktop and mobile move records. Desktop users will see a floating card tooltip on hover/focus; mobile users will see a non-intrusive floating popover on tap that dismisses on outside touch without interfering with board state or scrubbing.

- `src/components/CardArt.tsx`
- `src/components/PlayingCard.tsx`
- `src/utils/moveNotation.ts`
- `src/engine/cards/releaseRoster36.ts`

       - Find card definition in `RELEASE_ROSTER_36` by code.

    3. Desktop Hover Tooltip:
       - Hovering or focusing badge triggers a floating card preview positioned above/below the tag.
       - Preview displays: Card name, piece anchor badge, energy cost (0), vector art `<CardArt />`, condition pill, and effect rules copy.
       - Framed in dark slate `#161B22` with border tinted by piece color.
       - Disappears cleanly on `onMouseLeave` or `onBlur`.
    4. Mobile Tap Popover:
       - Tapping badge opens a non-intrusive floating card preview pill/card.
       - Does NOT wake up or block the entire screen; positioned near the tape with a subtle backdrop.
       - Includes an explicit close button ('✕') and automatically dismisses on outside click or second tap.
       - Crucial: Stop event propagation (`e.stopPropagation()`) so tapping the badge never triggers the parent move row or timeline scrubber.
  </action>
