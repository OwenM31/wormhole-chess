  <name>Task 1: Refine extraSquareFirst (N5, R1) vs toFirst (N3, Q2, P4, K3) Staging in useDeckChessGame.ts</name>
  <files>src/hooks/useDeckChessGame.ts</files>
  <action>
    In `src/hooks/useDeckChessGame.ts`:
    1. Create a small helper `isExtraSquareFirstCard(moves: EmpoweredMove[]): boolean`:
       - Returns `true` if `moves.some((m) => m.stageExtraSquareFirst || m.cardId === 'r1_make_way' || m.cardId === 'n5_get_to_the_king')`.
    2. When a card is armed (`selectCardFromHand` or `handleSquareClick` when selecting an anchor piece):
       - If `isExtraSquareFirstCard(anchorMoves)`:
         - For `n5_get_to_the_king`, ALWAYS set `setDisambiguationCandidates(anchorMoves)` when the Knight is selected (even if there is only 1 unique `extraSquare` `S1`), so the player first sees and clicks the forking square `S1` (`extraSquare`), and clicking `S1` then narrows `setEmpoweredMovesForSelected(matchingCandidate)` and clears `setDisambiguationCandidates(null)` to reveal all second-hop squares `S2` (`m.to`)!
         - For `r1_make_way`, preserve existing behavior (if `extraSquares.length > 1`, enter `disambiguationCandidates`; if `1`, show `to` squares).
       - If NOT `isExtraSquareFirstCard(anchorMoves)` (`to`-first cards like `N3`, `P4`, `Q2`, `K3`, `B6`, `B7`):
         - Do NOT immediately enter `disambiguationCandidates` upon selecting the anchor piece! Instead, show all destination squares `m.to` on the board first.
         - When the player clicks a destination square `square` (`matchingEmpowered = empoweredMovesForSelected.filter((m) => m.to === square)`):
           - If `matchingEmpowered.length === 1`, set `setPendingCardMove(matchingEmpowered[0])` immediately!
           - If `matchingEmpowered.length > 1`, set `setDisambiguationCandidates(matchingEmpowered)` so the player clicks which `extraSquare` (e.g. which L-path in `N3`, which ally in `Q2` / `K3` / `P4`) to use!
    AVOID: Forcing players to disambiguate `extraSquare` before clicking `to` on `to`-first cards when different `to` squares already uniquely determine the `extraSquare`.
  </action>
  <verify>npm run typecheck</verify>
  <done>useDeckChessGame.ts supports 2-click S1 -> S2 staging for N5 and destination-first disambiguation for N3, Q2, P4, and K3.</done>
