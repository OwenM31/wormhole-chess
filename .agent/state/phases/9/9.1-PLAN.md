<task type="auto">
  <name>Task 2: Implement Per-Ply Snapshots & Read-Only Scrubber in useDeckChessGame.ts</name>
  <files>src/hooks/useDeckChessGame.ts</files>
  <action>
    Update `src/hooks/useDeckChessGame.ts`:
    1. Extend `CombatLogEntry` with optional `plyIndex?: number` (`-1` for initial setup, `0..N-1` for recorded turns).
    2. Extend `RecordedTurn` with `plyIndex: number` and `stateSnapshot: DeckChessEngineState`.
    3. Track `initialStateSnapshotRef = useRef<DeckChessEngineState>(engineRef.current.getState())` (updated on `resetGame`) and `viewPlyIndex: number | null` (`useState<number | null>(null)`).
    4. In `addLog(text, type, color, plyIndex?)`, store `plyIndex` on the `CombatLogEntry`.
    5. In `makeMove`, `confirmPendingCardMove`, `triggerAiTurn` (both empowered and standard branches), and `applyRemoteTurn`:
       - Compute `const snapshot = engineRef.current.getState();` immediately after executing the move on `engineRef.current`.
       - Record `plyIndex` (`prev.length`) and `stateSnapshot: snapshot` on the `RecordedTurn`, and pass `plyIndex` to `addLog(...)`.
       - Reset `setViewPlyIndex(null)` when a live player move is made; in `resetGame`, reset `setViewPlyIndex(null)` and update `initialStateSnapshotRef.current = engineRef.current.getState()`.
    6. Implement timeline navigation callbacks:
       - `stepToPly(targetPly: number | null)`: if `recordedTurns.length === 0` or `targetPly === null` or `targetPly >= recordedTurns.length - 1`, set `viewPlyIndex(null)`; else clamp to `Math.max(-1, targetPly)`, call `cancelPendingCardMove()`, and set `viewPlyIndex(clamped)`.
       - `stepBackward()`: if `recordedTurns.length === 0`, return; const current = `viewPlyIndex === null ? recordedTurns.length - 1 : viewPlyIndex`; if `current > -1`, call `stepToPly(current - 1)`.
       - `stepForward()`: if `viewPlyIndex === null`, return; call `stepToPly(viewPlyIndex + 1)`.
       - `jumpToStart()`: if `recordedTurns.length === 0`, return; call `stepToPly(-1)`.
       - `jumpToLive()`: call `stepToPly(null)`.
    7. Derive `totalPlies = recordedTurns.length`, `activePlyIndex = viewPlyIndex !== null ? Math.min(viewPlyIndex, totalPlies - 1) : totalPlies - 1`, `isViewingHistory = viewPlyIndex !== null && viewPlyIndex < totalPlies - 1`, and `viewedMove = activePlyIndex >= 0 ? recordedTurns[activePlyIndex] || null : null`.
    8. Derive `displayedState: DeckChessEngineState`:
       - When `!isViewingHistory`, return `gameState`.
       - When `activePlyIndex === -1`, return `initialStateSnapshotRef.current`.
       - When `activePlyIndex >= 0` and `recordedTurns[activePlyIndex]?.stateSnapshot`, return `recordedTurns[activePlyIndex].stateSnapshot`.
    9. Compute `evaluation` using a temporary `DeckChessEngine` cloned/loaded with `displayedState` when `isViewingHistory` is true, or `engineRef.current` when live, so `<EvalBar />` updates accurately during rewind!
    10. Enforce **Read-Only Guards (`INV-REW-01`)**:
        - In `handleSquareClick`, `selectCardFromHand`, `makeMove`, `confirmPendingCardMove`, and `applyHintMove`: if `isViewingHistory` is true, return early without mutating engine state.
    11. Expose `viewPlyIndex`, `activePlyIndex`, `totalPlies`, `isViewingHistory`, `viewedMove`, `stepToPly`, `stepBackward`, `stepForward`, `jumpToStart`, and `jumpToLive` from `useDeckChessGame` and on `window.__DECK_CHESS_GAME__`.
    AVOID: Mutating `engineRef.current` during `stepToPly` because rewind is strictly read-only inspection and must never corrupt an active AI or multiplayer match.
  </action>
