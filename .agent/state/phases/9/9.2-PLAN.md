  <files>src/pages/DeckBuilderPage.tsx, src/pages/PlayRoomPage.tsx, src/components/DeckChessBoard.tsx</files>
  <action>
    1. In `src/components/DeckChessBoard.tsx`:
       - Add optional props `lastMoveFrom?: string | null`, `lastMoveTo?: string | null`, `isViewingHistory?: boolean`, and `onReturnToLive?: () => void`.
       - Highlight `lastMoveFrom` and `lastMoveTo` squares with a subtle warm amber tint (`bg-[#D4AF37]/20`) when no active piece selection overrides them.
       - When `isViewingHistory` is true, render a compact non-intrusive top-center badge inside the board frame (`data-testid="board-history-banner"`): `"⏪ Viewing Past Move — Click to Return Live"` that calls `onReturnToLive?.()` when clicked.
    2. In `src/pages/DeckBuilderPage.tsx`:
       - Pass `lastMoveFrom={game.viewedMove?.chessMove?.from}`, `lastMoveTo={game.viewedMove?.chessMove?.to}`, `isViewingHistory={game.isViewingHistory}`, and `onReturnToLive={game.jumpToLive}` to `<DeckChessBoard />`.
       - Inside the Right Column (`Moves` tab, `<div className="flex-1 my-2 overflow-hidden flex flex-col">`):
         - Render `<RewindBar />` with `className="order-1 lg:order-2 mb-2 lg:mb-0 lg:mt-2 shrink-0"` so that on mobile (`< lg`), the Rewind Bar sits **above the scrolling Move Log** (immediately below the Tactical Hand), and on desktop (`>= lg`), it sits **below the scrolling Move Log** (above the Action Footer).
         - Render the scrolling Move Log container with `data-testid="move-log-scroll-container"` and `className="order-2 lg:order-1 flex-1 overflow-y-auto pr-1 space-y-1 font-mono text-xs min-h-[140px]"`.
         - When `game.totalPlies > 0`, include a clickable `"Starting Position"` row (`data-testid="move-log-ply--1"`) at the top that calls `game.stepToPly(-1)` and highlights when `game.activePlyIndex === -1`.
         - For each entry in `game.combatLog`:
           - If `typeof log.plyIndex === 'number'`, make the row a clickable button/div (`data-testid={`move-log-ply-${log.plyIndex}`}`, `onClick={() => game.stepToPly(log.plyIndex!)}`) with a `#${log.plyIndex + 1}` ply badge and gold active highlight (`border-[#D4AF37] bg-[#D4AF37]/15 ring-1 ring-[#D4AF37]/40`) when `game.activePlyIndex === log.plyIndex`.
         - Update the Move Log auto-scroll `useEffect` so that whenever `game.combatLog.length` OR `game.activePlyIndex` changes, it scrolls the active row into view strictly via `moveLogContainerRef.current.scrollTop` arithmetic (never calling `window.scrollTo` or page-scrolling `scrollIntoView`), preserving `INV-REW-04 (Scroll Anchor Stability)`.
    3. In `src/pages/PlayRoomPage.tsx`:
       - Render `<RewindBar />` below the `TacticalHandBar` in Deck Builder mode and pass `lastMoveFrom`, `lastMoveTo`, `isViewingHistory`, and `onReturnToLive` to `<DeckChessBoard />`.
    AVOID: Using `element.scrollIntoView()` on Move Log rows because on mobile viewports `scrollIntoView()` scrolls the entire `window` away from the chessboard. Always adjust `moveLogContainerRef.current.scrollTop` directly.
  </action>
