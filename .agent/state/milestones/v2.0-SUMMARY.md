## Lessons Learned

1. **Restrained Copy Elevates Engineering Credibility**: Users strongly prefer concise, functional copy ("Home of your favorite chess variants") over dramatic AI-generated corporate filler.
2. **Unified Action Model Eliminates Interaction Disconnect**: Moving away from separate "pre-move card play" phases to "The Card IS the Move" vastly simplified state handling and gameplay feel.
3. **Multi-Viewport Responsive Audits Catch Real Bugs**: Testing with Playwright at 375px and 1440px caught sidebar layout clipping, table overflows, and CSS shorthand property collisions before they reached production.
