## Overview

Wormhole Chess is a client-side 3D chess variant web application rendered with Three.js and React Three Fiber. The game features a non-Euclidean board topology with top and bottom boards connected through a curved wormhole throat, supporting custom directional move topologies, 3D piece animation, and local turn-based play.

## Data Flow

1. **User interaction:** User clicks a piece or square in the 3D Canvas (`OrbitControls` handles camera, raycaster handles click events).
2. **Move calculation:** `ChessboardScene` queries `boardGraph` in `WormholeTopology.tsx` to traverse rays and calculate legal destination squares from the selected piece.
3. **State update:** Clicking a legal square updates piece state, records the move in `moveHistory`, handles captures, and increments `currentPlayer`.
4. **Transform & Render:** Piece coordinates are translated into 3D vectors via `chessToWorld()` in `CoordinateConversion.tsx` and `WormholeGeometry.tsx`.
5. **Spring physics:** `@react-spring/three` smoothly interpolates piece position along calculated paths.

## Technical Debt & Architectural Gaps

- [ ] **Monolithic God Component:** `ChessboardScene.tsx` is ~2,941 lines, tightly coupling 3D rendering, game rules, HUD, and state. Needs refactoring into decoupled modules: Game Engine, 3D Board View, and UI Overlay.
- [ ] **Deprecated Build Tooling:** Built on Create React App (`react-scripts` 5.0.1) with 2-minute build times and deprecation warnings. Should be migrated to **Vite** for fast HMR and Cloudflare compatibility.
- [ ] **Zero Backend / Persistence:** No database or API layer. All moves, user settings, and states exist purely in client-side ephemeral React state.
- [ ] **Missing Client Routing:** No router (`react-router-dom`), preventing landing page, user dashboard, authentication screens, and game variant selection.
- [ ] **Variant Inflexibility:** Game engine logic is hardcoded specifically to the 3D Wormhole graph. No abstract engine interface exists for adding "Deck Builder Chess" or standard chess.
- [ ] **Broken Boilerplate Test:** `src/App.test.tsx` fails looking for CRA's "learn react" anchor tag.
- [ ] **Outdated README:** Documentation describes an obsolete AWS EC2 SSH/scp workflow, whereas production is deployed to Cloudflare Pages.
